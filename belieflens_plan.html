Research program · belief dynamics in judgmental forecasters

What moves an LLM's belief?

LLM forecasters are judgmental forecasters — they hold positions of their own, and FutureSim already shows they sometimes will not let go of them. That is a claim about belief dynamics, and it cannot be settled without a representation of belief you can intervene on and measure distance in. This is the program for building that instrument and running it until the laws come out.

The premise

The representation is an instrument, not a thesis

Analytica's proposition tree is one way to externalise a belief. Agent-BRACE's claim set with ordinal certainty is another. A bare string is a third. None of them is the object of study — the belief is. So the right question is not is the tree correct but what must any representation support if we want to derive properties of belief from it. Five requirements, and they are what the design answers to:

R1 elicitableThe model can produce it, or we can reconstruct it from behaviour. Both routes matter: what it says its belief is, and what its choices reveal.
R2 metricThere is a meaningful distance between two belief states — across time, across interventions, across models. This is the load-bearing requirement, and it is where trees fail: two elicitations of one question yield different nodes, so edit distance over free-text claims is a swamp.
R3 addressable
hardThe representation has parts you can name and change — “set this claim to 0.9”, “retract this one”. Intervention needs an address, nothing more. This, and not computation, is the real argument for structure: a bare string has nowhere to point.
R4 decodableIt maps to a forecast, so it can be scored against behaviour and against outcomes.
R5 refinableA coarse belief (one number) and a fine one (a whole structure) must be relatable by projection — otherwise you cannot ask whether elaborating a belief preserves it.
R6 executable
softIf the composition can be run by machine, an intervention's implied consequence comes back exact and free. Worth having — not worth distorting the belief to obtain. See the next section: the model can always run its own belief instead.

Against the candidates: a tree with a linear rule satisfies R3, R4 and R6, and fails R2 and R5. A flat claim set satisfies R2 and R3 but has no composition, so it cannot say what should follow — it fails R6, and needs the model itself to supply the consequence. A bare string fails at R3 and takes everything downstream with it. Nothing here is the answer; the requirements are.

The representation

A belief state is a triple

B = ( C , π , f )
C the frame — which propositions are in play. π the credences over them, with resilience. f the aggregator — how they compose. Each of the three is a separate experimental handle, and separating them is most of the design.

C — the frame, in two modes

Free-frame: the model authors its own proposition set. This is itself a readout — what structure does it spontaneously build, and how stable is that across redraws?

Fixed-frame: we supply a canonical probe battery per question — the question, its negation, a handful of sub-questions, a few conditionals, generated once and reused. The model only fills in credences. Now a belief state is a vector in [0,1]n in a shared coordinate system: distances are trivial, dynamics are literally trajectories you can plot, and interventions have well-defined coordinates.

This is the answer to “maybe we don't need a tree.” What we need is not a richer nested structure — it is a coordinate system for beliefs. Free-frame for statics, fixed-frame for dynamics.

π — credence with resilience, not a bare number

A point probability does not determine how a belief should move. So each credence is a pair (p, n): the value, and an equivalent sample size — “I hold 0.7 as if on twelve observations” versus “as if on two.” Evidence of weight m then implies a specific posterior, (pn + m)/(n + m), in the model's own units. Over- and under-reaction become measurable without installing an external Bayesian referee whose priors we would then have to defend.

f — the aggregator is elicited, not imposed

Why linear? Analytica picked it for variance averaging and a closed-form analysis. Nothing in this program needs linearity — and, per R6, nothing strictly needs a closed form at all. So the grammar runs from fully executable down to frankly vague, and the model picks its own rung:

f :=  — executable: an intervention's consequence comes back exact —
         LINEAR(β₀, β…)          // Analytica's rule, one option among many
      |  NOISY_OR | NOISY_AND    // independent sufficient causes / joint necessity
      |  LOGISTIC(b, w…)         // saturating evidence accumulation
      |  MIN | MAX               // weakest-link, best-case
      |  MIX(λ, f₁, f₂)          // regime mixture: "usually additive, sometimes gated"
      |  TABLE(cpt)              // full conditional table, small parent sets
      |  EXPR(arithmetic)        // escape hatch, still runnable

      — partial: constrains the consequence without fixing it —
      |  MONOTONE(↑n1, ↓n4)      // direction only
      |  DOMINATES(n1 ≫ n2)      // relative weight, no magnitudes
      |  GATED(n3 → then n1)     // structure without parameters

      — vague: natural language, run by the model —
      |  NL("n1 only matters if n3 holds; otherwise it is mostly n2,
             and n4 caps the whole thing")

LINEAR cannot express "these two only matter jointly". NOISY_OR cannot
express inhibition. And no closed form expresses a belief the model holds
but has not made precise — forcing one on it discards exactly the part we
are trying to read.

Letting the model state its own composition semantics — at whatever precision it actually has — turns the aggregator from an assumption into data: which forms do models reach for, for which kinds of question, and how much of a belief will a model commit to executable form at all? That commitment rate is a measurement in its own right, and the executable fragment can then be compared against the vague remainder to see whether pinned-down beliefs behave differently from unpinned ones.

And it opens the sharpest single experiment in this section.

stated f  vs  revealed f
The elicited f is the model's stated theory of how its own beliefs cohere. Now clamp nodes — “suppose n3 = 0.9” — over a battery of clampings and record the root the model itself re-derives. Fit each candidate family to those responses: the best-generalising fit is the revealed aggregator. Note the asymmetry — the revealed rule is always ours and always runnable because we fit it, so the stated one never has to be. It only has to be sampleable, and the model can sample even an NL(…) rule on a grid. That is a direct answer to what rule does the model implement, rather than one we imposed.
The DSL

BeliefSpec, assembled

The triple written out — and deliberately not a tree. Claims are a flat, addressable set; structure lives in a separate relations list. A tree is simply what you get when every claim composes into exactly one other and nothing else is declared, which makes Analytica's shape a special case rather than the schema.

Flattening is not tidiness. It is what the rest of the design already assumed: a shared coordinate system cannot exist if each elicitation nests differently (R2, R5); a claim genuinely does bear on more than one question, which a tree forbids; and the coherence laws need relations that have no direction at all — a complement, a mutually exclusive outcome set, a conjunction bound — which a parent-child edge has nowhere to put.

{
  "question": "Will the ECB cut its deposit rate at or before the March 2026 meeting?",
  "as_of":  "2025-12-24",
  "frame":  "fixed:ecb-rate-v1",   // C — free, or a named shared battery (R2, R5)
  "query":  "c_cut",               // which claim we happen to forecast. NOT a root —
  "interpreter": "exec",           //    no structural privilege, just a pointer

  "claims": [                       // π — flat, unordered, every one an ADDRESS (R3)
    { "id": "c_cut",  "text": "The ECB deposit rate is cut at or before March 2026",
      "p": 0.58, "n": 6, "wep": "possible" },     // n = resilience: "as if on 6 observations"

    { "id": "c_core", "text": "Euro-area core inflation prints below 2.0% for two months",
      "p": 0.34, "n": 9, "wep": "unlikely",       // n=9 → held firmly, should barely move
      "sensitivity": [                            // stated BEFORE any evidence arrives
        { "if": "January flash core at or below 1.9%", "p_to": 0.72, "weight": 4 },
        { "if": "January flash core at or above 2.3%", "p_to": 0.11, "weight": 4 } ] },

    { "id": "c_gdp",   "text": "Euro-area Q4 GDP is revised negative",
      "p": 0.22, "n": 3, "wep": "unlikely", "sensitivity": [ … ] },  // n=3 → should swing

    { "id": "c_hawks", "text": "A Governing Council majority signals easing publicly",
      "p": 0.41, "n": 2, "wep": "possible", "sensitivity": [ … ] },

    { "id": "c_nocut", "text": "No cut at or before March 2026", "p": 0.39, "n": 6, "wep": "possible" }
  ],

  "relations": [                    // f lives here — as ONE kind of relation among several
    { "kind": "composes", "into": "c_cut", "from": ["c_core","c_gdp","c_hawks"],
      "f": { "rung": "executable", "form": "NOISY_OR",
             "over": { "c_core": 0.70, "c_gdp": 0.45, "c_hawks": 0.25 } } },

    // relations a parent-child edge cannot express:
    { "kind": "constrains", "form": "COMPLEMENT", "over": ["c_cut","c_nocut"] },   // A3
    { "kind": "constrains", "form": "IMPLIES",  "from": "c_gdp", "to": "c_cut" },     // holds
    { "kind": "constrains", "form": "FRECHET",  "over": ["c_core","c_gdp"] }          // regardless of f
  ]
  // c_core also appears in the ECB-March-hold spec. One claim, two questions —
  // which is exactly what a tree forbids and a relation list gets for free.
}

The same composition at the other two rungs — the model picks, and we record which:

  "f": { "rung": "partial", "form": "MONOTONE", "up": ["c_core","c_gdp"],
                            "dominates": "c_core ≫ c_hawks" }

  "f": { "rung": "prose", "form": "NL",
         "text": "c_core is the whole story unless growth cracks; c_hawks only
                  matters if c_core is already close, and hawkish remarks cap it" }

Two small fields carry more than their size. "n" beside every "p" makes over- and under-reaction measurable in the model's own units — c_core at n=9 should barely move where c_gdp at n=3 should swing, and a model that moves them equally has told on itself. And "weight" inside each sensitivity slot is the evidence weight that pairs with it, so a cue commits the model to both a destination and an implied change in how firmly it will hold that value afterwards. Both halves are checkable.

Probes are verb, address, value

This is the whole payoff of addressability. Every experiment in the battery is one line against a live spec, and not one of them requires the spec to be runnable.

clamp    c_core := 0.90            // A5 · sweep, record the query value it re-derives → revealed f
tamper   c_gdp.p += 0.25           // A12 · hand back as if untouched; P(detect | Δ) → uptake
inject   e17 → c_core              // A6 · the model's own cue, returned as dated news
retract  e17                       // A8 · "that report was withdrawn". is B restored?
permute  [e17, e23] → [e23, e17]   // A7 · does arrival order change the destination?
freeze   relations                 // A10 · local protocol: only π may move
refine   c_core → 4 claims         // A4 · does elaborating change what B decodes to?
replace  f(c_cut) := ⟨M2's f⟩      // transplant · whose belief is the model acting on?
project  onto frame:ecb-rate-v1    // R5 · re-express a free-frame belief in the shared basis
step     ∅                         // A9 · a day with no evidence. does B drift anyway?

A belief written as a paragraph supports none of these lines. That, and not arithmetic, is what the structure is for.

Who runs the belief

The model can be its own interpreter

Once a belief is crystallised into a representation, there are two ways to find out what it implies. We can run it. Or we can hand it back to the model and ask it to play — condition it on its own belief state and let it produce the forecast, answer the conditional, take the update. The second route needs no closed form, no grammar, and no arithmetic on our side, which is why R6 is soft: the experiment does not require the belief to run by itself.

This is also the deployment-realistic setting. Agent-BRACE's policy conditions on the belief state directly; nothing in that architecture ever executes it. A belief that only means something when a separate interpreter runs it is not the belief the agent is acting on.

Uptake, then compliance

Uptake is the sensitivity of D_model(B) to perturbations of B — and it is the tamper probe of A12 seen from the other side. Zero uptake means the model is not reading its belief state; it is answering the question the way it would have anyway. Compliance is |D_exec(B) − D_model(B)|: whether the model honours the rule it wrote down. Compliance is only interpretable once uptake is non-zero.

The important consequence: because the MODEL route is always available, the whole battery degrades gracefully to a belief written as plain prose. The DSL is a precision upgrade, not a prerequisite — which also means the program is not hostage to models emitting well-formed JSON.

So what does executability actually buy?

Most of the battery does not need it. Several probes have no f in the loop at all.

It earns its place in four, and they are worth keeping a lane open for.

E1 unfakeableThe referee must not be the defendant. Rigidity is 1 − actual/implied. If implied is also model-produced, both sides of the ratio are under the model's control at judgment time — it can understate what its belief required and look faithful. Machine execution makes implied unfakeable.
E2 noiselessWith EXEC, interpreter noise is zero, so all observed variance is belief variance. With MODEL you cannot separate an unstable belief from an unstable reading of it.
E3 geometryDistance between two aggregators, full sensitivity surfaces, Shapley attribution over claims — Monte Carlo over the credence cube, thousands of evaluations per node. Free with EXEC, financially impossible with MODEL. These experiments only exist if f runs.
E4 baselineThe one worth fighting for. Take the day-0 rule, run it forward on FutureSim's real 88-day evidence stream without the model, and compare with what the model actually did. Single-shot rigidity becomes accumulated divergence — which is the phenomenon FutureSim actually reports. Unobtainable from the model, because asking it to simulate its own consistent updating is precisely the thing under measurement.
the principle is not executable — it is independent of the belief-holder at judgment time
Machine execution is just the limiting case: maximally neutral, zero noise, free. A cheap separate model reading an NL(…) rule is a weaker version of the same thing — it covers E1 and partly E2, and neither E3 nor E4.

The resolution: relax it, and make the relaxation a result

  • The model picks its own rung on the grammar, and we record the rung. The commitment rate — how much of a belief a model will pin to runnable form — becomes a variable rather than a constraint.
  • The executable subset is the sample for E1–E4. Everything else runs on the full sample through MODEL.
  • Which yields a result you cannot get if executability is forced: are pinned-down beliefs more or less rigid than vague ones? Same model, same questions, split by rung.
  • An auto-compile step — a cheap separate model compiles NL(…) into runnable form — gives compile success rate, wider EXEC coverage, and a check on whether the compiled rule predicts what the model's own play-forward does. Compilation loss becomes measured instead of assumed.
  • And the distortion worry becomes testable head-on: elicit both a free-form and a forced-executable f from the same model on the same question, then compare them in d₂. If being made precise changes how a belief updates, that is a real finding about elicitation format — an A2-flavoured one.
Measurement

The distance ladder

Every experiment below reduces to “how far did the belief move, and in what sense.” Three levels, strictly increasing in information and cost.

d₀
Decoded. |D(B₁) − D(B₂)|, or TV / Wasserstein over the outcome distribution. Always defined, essentially free. FutureSim already uses TV distance implicitly in its multi-agent convergence result.
d₁
Content. Match claims across frames — identity in fixed-frame, bidirectional-entailment matching in free-frame — then an earth-mover cost over matched credences plus a penalty for unmatched mass. This is what makes two different decompositions comparable: never compare trees, compare the claim–credence measures they induce.
d₂
Dispositional. Ee|U(B₁,e) − U(B₂,e)| over a standard evidence battery. Two beliefs are the same iff they update the same. The Dennettian metric — beliefs individuated by dispositions, not text. And the elicited conditional slots are already a finite sample of the update map, so d₂ is estimable with no new model calls.

Two derived quantities matter as much as the metrics themselves.

  • The noise floor. d(B, B′) between two independent elicitations of the same question is both the bar every effect must clear and a measurement of how crisp the belief is. Some questions may have no determinate belief at all — dispersion tells you which, and that is a finding, not a nuisance.
  • The post-hoc signature, purely metric. Resampled beliefs that are close in d₀ but far in d₁ mean a stable conclusion resting on unstable rationale. Rationalisation, detected without any decoder trickery.
The core battery

Twelve laws, and the violation is the measurement

An ideal belief-holder satisfies a short list of identities. Each identity is one experiment; what we record is the violation, in units of one of the distances. This is how behavioural economics took apart the rational-agent axioms, pointed at judgmental forecasters that happen to be language models — and it turns “there are a lot of variations” into a closed, enumerable program rather than a grab-bag.

A12 carries the most weight, because it is the one that operationalises whether beliefs are internally recoverable at all. It yields a full psychometric curve — a just-noticeable difference for belief tampering. If a model cannot detect a shift below Δ ≈ 0.3, then to that resolution its verbalised belief is not introspectively real; it is being generated on demand at the moment of asking. Treating the model as a psychophysics subject with a discrimination threshold on its own belief states is, as far as I can find, unexplored territory — adjacent to injected-thought introspection work, but behavioural and forecasting-native.

Beyond the axioms

Three dynamics that are not identities

attractor dynamics
Iteration fixed points
Bn+1 = g(Bn) — “re-read your belief and refine it,” no new evidence. Does g converge, drift, or contract toward the extremes? FutureSim's self-conditioning, where models treat their own past rationales as hard truths, is exactly this map having the wrong fixed points. An overconfidence spiral is g contracting toward {0,1}, and its rate is measurable.
causal encoding
Transplant
Give model M₂ a belief state authored by M₁, presented as its own. If M₂'s later forecasts and updates move toward M₁'s, the representation causally carries the belief — encoding demonstrated by transfer rather than by correlation. Its converse is the identification test: from behaviour alone, can you tell who authored a belief state? If beliefs are recoverable and model-specific, fingerprinting succeeds.
belief read from deeds
Value-of-information coherence
In FutureSim the agent also acts — it chooses what to search for. Its own conditional slots imply which news would be most informative. Does its search behaviour actually target those claims? This is the bridge from stated belief to agentic behaviour: belief read out of what the model does, not what it says.
The environment

What FutureSim is for — three things, and a leaderboard last

  • The evidence stream. Real dated news, replayable, with controllable order — which is precisely what A7, A8 and A9 require and what no synthetic setup can supply credibly. The injected-cue probes already built are the pilot; the replay upgrades every dynamics axiom from synthetic stimulus to real arriving information.
  • The trajectory. Fixed-frame plus daily replay makes each question a curve in [0,1]n over 88 days: velocity, jumps at news events, mean reversion, diffusion on quiet days. Belief dynamics becomes literally visible. It also gives the memory experiment FutureSim gestures at — run identical days under raw history, under summary, and under an explicit belief state carried forward, and test Agent-BRACE's sufficient-statistic claim in a forecasting setting, with no RL required.
  • The social layer. FutureSim showed multi-agent forecasts converge toward the aggregate despite anti-herding incentives. With belief states you can ask at which level they converge: close in d₀ but not d₁ means agents copied conclusions without reasons — herding. Converging in d₁ too means genuine persuasion. The benchmark alone cannot tell these apart; the representation can.
  • Then the scoreboard. Once questions resolve, the properties become predictors: does rigidity, perseverance, or order-dependence predict Brier trajectory? That is the result that makes this a forecasting paper and not only a psychology paper — belief pathologies that cost measurable skill.

Honesty

What this cannot show

  • These are stated beliefs. Everything here is defined on what the model reports, under repeated sampling and under intervention. The defensible claim is consistency of stated belief across formats, across time, and under manipulation. Logprob readouts on an open-weight model are the one bridge toward anything internal, and A12 is the one probe that speaks to access rather than consistency.
  • Faithfulness is not accuracy. The evidence-free phase needs no ground truth, which is why it is fast — but it also cannot say whether the beliefs are any good. Accuracy claims need questions genuinely past each model's cutoff, and the cutoffs belong in the table.
  • Sampling noise is not temperature-controlled. Current reasoning models reject the temperature parameter outright, so repeated draws are ordinary sampling variation. Disclose it; don't paper over it with a prompt nonce.
  • Rigidity and poor instruction-following look alike. A model that ignores a frozen-f protocol may simply be bad at constrained editing. Report format-compliance rate beside every rigidity number, and keep the no-representation control that decides whether a pathology belongs to the representation or to the model.

What changes from here

The deltas are small, because the harness was built around interventions rather than around Analytica:

  • rule: "linear" becomes f: a rung on the grammar, chosen by the model, plus a swappable interpreter — EXEC for runnable rungs, MODEL for any rung including prose. The rigidity identity survives untouched under either.
  • An uptake probe that runs before anything else on every question, since no compliance or rigidity number means anything until the model is shown to be reading its own state.
  • p becomes a resilience pair (p, n).
  • A frames.py that generates the fixed probe battery per question, and a distances.py implementing d₀ / d₁ / d₂ plus the function-space distance between aggregators.
  • New probes, each a prompt plus bookkeeping on infrastructure that already runs: clamp, retract, permute-order, tamper, transplant, iterate.
The one open decision

Which cluster is the spine

All three share the representation and the distance ladder, so nothing is wasted whichever way this goes. But the choice decides whether fixed-frame or free-frame elicitation gets built first.

A — the axiom battery

deepest · newest · riskiest

Trajectories, perseverance, order effects, and properties that predict skill. Strongest tie to the benchmark and to accuracy, heaviest infrastructure: corpus, index, long-horizon runs.
